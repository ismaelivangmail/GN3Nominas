# GN3Nominas

Este proyecto fue creado en [Angular CLI](https://github.com/angular/angular-cli) versión 22.0.0.  

## Development server

Para iniciar el proyecto, ejecutar comando:

```bash
ng serve -o
```

Una vez que compilado con éxito se abrirá  `http://localhost:4200/`.
