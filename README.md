# GN3Nominas

Este proyecto fue creado en [Angular CLI](https://github.com/angular/angular-cli) version 22.0.0.

## Development server

Para iniciar el proyecto, correr:

```bash
ng serve -o
```

Una vez que sea ejecutado con éxito se abrirá  `http://localhost:4200/`.
La aplicación se recargará automáticamente cada vez que modifiques alguno de los archivos fuente.
